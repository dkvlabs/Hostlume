# Architecture Decision Record template

Save a new copy as `docs/decisions/ADR-00XX-short-name.md` when an architecture decision changes the implementation or deployment model.

```md
# ADR-00XX: <title>

Status: proposed | accepted | superseded
Date: DD.MM.YYYY
Owner: <person/agent>
Related features: FX-...

## Context
What problem forces a choice? Which OS/hardware and security constraints matter?

## Decision
Exactly which alternative was chosen, with boundaries.

## Alternatives considered
A, B, C: benefits/costs, platform/API/licensing risk.

## Consequences
New code boundaries, changes to tests, documentation and installers.

## Evidence
Official docs, real hardware spike, test commands and exact outcomes.

## Follow-up
What remains unverified and when must this ADR be revisited?
```
